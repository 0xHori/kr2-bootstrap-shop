## 1. Описание проекта

Проект представляет собой тематический интернет-магазин виниловых пластинок и аудиорелизов **«CuteRock Vinyl»**, разработанный на базе фреймворка **Bootstrap 5.3**.  
Интерфейс спроектирован по требованиям методических указаний к Практическим занятиям №9–11 и Контрольной работе №2 с глубокой проработкой пользовательских сценариев, семантики и адаптивности.

---

## 2. Способ подключения Bootstrap

- `vendor/bootstrap/css/bootstrap.min.css` — скомпилированная CSS-библиотека Bootstrap 5.3;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript-бандл с включённым Popper.js для работы dropdown, modal, carousel, tabs и accordion.

Кастомный файл `css/custom.css` подключён строго после стилей Bootstrap для безопасного переопределения правил без нарушения каскада и специфичности.

## 3. Самостоятельные доработки проекта

1. **Автономное подключение Bootstrap:** локальное размещение CSS и JS бандлов в каталоге `vendor/bootstrap/` с отказом от внешних CDN.
2. **Расширение структуры проекта:** добавлена полноценная страница **`contacts.html`** с реквизитами, расписанием, интерактивными ссылками связи и формой обратной связи.
3. **Расширенный пул Bootstrap-компонентов:**
   - **Carousel (Карусель):** промо-слайдер в hero-блоке главной страницы с таймингом и индикаторами;
   - **Tabs (Вкладки):** интерактивное переключение «Характеристики / Описание и треклист / Доставка» на странице товара `product.html`;
   - **Button Group (`btn-group`):** переключатель физического формата носителя (LP / Digipak / MC) через радиокнопки Bootstrap в карточке и модальном окне;
   - **Pagination (Пагинация):** компонент навигации по страницам каталога;
   - **Accordion (Аккордеон):** интерактивный FAQ-блок с тремя раскрывающимися секциями;
   - **Navbar Cart Badge:** интеграция счётчика корзины с бейджем `badge bg-danger` в навигационную панель на всех страницах.
4. **Проработка каталога и пользовательского пути:**
   - Интерактивная панель фильтрации по музыкальным жанрам и сортировки по цене в `catalog.html`;
   - Каталог из 6 уникальных релизов с квадратными обложками 1:1 (`aspect-ratio: 1/1`), реальными треклистами, лейблами и статусами (`Новинка`, `Хит`, `Скидка`, `В архиве`, `Рекомендуем`, `Эксклюзив`);
   - Аудиоплеер для превью трека на странице товара `product.html`;
   - Расширенная форма заказа в `order.html` с выбором способа получения (курьер / самовывоз / электронная копия).
5. **Визуальная целостность и верстка:**
   - Flexbox-архитектура Sticky Footer (подвал гарантированно прижат к низу экрана на любых мониторах);
   - Hover-анимация карточек (`transform: translateY(-2px)`);
   - Единая сквозная навигация и подвал с актуальным активным состоянием `.active` для текущей страницы.
6. **Адаптивность:** полная поддержка брейкпоинтов от мобильных экранов (360–430px) до десктопа (1440px+).
7. **Публикация через GitHub Pages:** сайт развернут в рабочей веб-среде и готов к проверке.

## 4. Используемые технологии и компоненты

### Стек:
- HTML5 (семантическая разметка, тег `<audio>`);
- CSS3 (кастомные утилиты, Flexbox, aspect-ratio);
- Bootstrap 5.3 (сетка, utility-классы, интерактивные компоненты);
- Git / GitHub / GitHub Pages.

### Компоненты Bootstrap в проекте:
- `container`, `row`, `col-12`, `col-md-*`, `col-lg-*` (12-колоночная адаптивная сетка);
- `navbar`, `navbar-toggler`, `collapse`, `dropdown` (адаптивная шапка с гамбургер-меню и выпадающими списками);
- `card`, `card-body`, `card-img-top` (карточки релизов и блоки контента);
- `btn`, `btn-primary`, `btn-outline-primary`, `btn-group` (кнопки и группы переключателей);
- `badge` (метки статусов и бейдж корзины);
- `alert` (информационные сообщения с кнопкой закрытия);
- `modal` (модальные окна быстрого бронирования);
- `form-control`, `form-select`, `form-check`, `input-group` (поля ввода, селекты, чекбоксы и группы с префиксами);
- `carousel` (слайдер на главной странице);
- `nav-tabs`, `tab-content` (вкладки на странице товара);
- `accordion` (раскрывающийся FAQ);
- `breadcrumb` (хлебные крошки);
- `pagination` (пагинация каталога);
- `table`, `table-responsive` (адаптивная таблица характеристик).
